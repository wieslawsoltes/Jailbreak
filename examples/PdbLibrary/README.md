# Verified binary source debugging

The package in `library.binary.json` is generated by `node scripts/generate-pdb-example.mjs` from the owned SDK fixture, `tests/fixtures/msil/pdb.json`. It is not a rewritten C# implementation. The package includes executable IL and Portable PDB symbols with embedded original source.

Enable **Develop → debugger / designer**, compile, and open the **[symbol]** Calculations.cs tab. Its contents are read-only and do not become source compilation inputs. Set a breakpoint on `total += i`, choose native DevTools breaks for native source stepping, then click **Call library Sum**. The output is `Library sum: 45`.

Release builds omit binary debug hooks and source-map text. The original-source checksum and DLL/PDB identity are required before any document is exposed as verified source.
