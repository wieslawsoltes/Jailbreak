JAILBREAK / COMPATIBILITY
A real compiler.
A deliberately explicit subset.
The XAML and C# compilers emit JavaScript. The same reusable libraries power this workbench and the exported application.
What runs
Code-behind, named controls, basic bindings, resources, simple styles, native input, selection and layout controls, plus a standalone WebGPU drawing surface with Canvas2D fallback. The upstream CheckBox page includes its original C# code-behind.
What is not a pass
The complete ControlCatalog, Avalonia templates, exact pixel parity, full MSBuild and NuGet evaluation, all C# semantics, arbitrary .NET APIs and native platform features are not implemented. Both included catalog pages retain their original code-behind. The ScrollPage theme is an explicit host adapter.
Project loading and execution
Open an entire source folder to preserve relative solution/project references. Single-file selection flattens paths. JSON workspaces round-trip all text files. Builds run in a worker; previews run with scripts only in an opaque-origin iframe. The preview has no network fetch permission. Only run source you trust: browser sandboxing is not a guarantee against CPU or memory exhaustion.
Keyboard
Command / Control + Enter builds. Command / Control + S downloads the workspace. Tab inserts four spaces. Edit files, inspect generated JavaScript, choose an entry view, or export a standalone HTML application.
